# osu! Mascot Archive — Testing Setup

## 1. Install Required Software

### Git

Arch / EndeavourOS:

```bash
sudo pacman -S git git-lfs
```

---

### Obsidian

Download:

https://obsidian.md/

---

# 2. Clone Repository

```bash
git clone git@github.com:USER/REPO.git
```

Example:

```bash
git clone git@github.com:FatalNight/osu-mascot-archive.git
```

---

# 3. Open Vault

In Obsidian:

```text
Open folder as vault
```

Select:

```text
osu-mascot-archive/
```

---

# 4. Install Community Plugins

Enable:

```text
Settings
→ Community Plugins
→ Turn off Safe Mode
```

Required plugins:

- Dataview
- Templater
- Metadata Menu
- Folder Notes
- Excalibrain
- Waypoint
- Custom File Explorer Sorting

---

# 5. Pull Latest Changes

Before starting work:

```bash
git pull
```
